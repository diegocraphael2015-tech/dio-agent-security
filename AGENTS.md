# DIO Agent — Tabela de Habilidades

O agente utiliza arquivos declarativos para selecionar a melhor abordagem de resposta.

| Skill | Gatilho / Cenário de Uso | Descrição |
| :--- | :--- | :--- |
| `vulnerability-analysis` | Análise de código, revisão de arquitetura, incidentes ou logs de segurança | Avalia contexto, risco (Impacto x Probabilidade), MITRE ATT&CK e prescreve código corrigido |
